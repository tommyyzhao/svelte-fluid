# ADR 0126: Opt-in passive flow tracers

**Status:** Accepted
**Date:** 2026-10-23

## Decision

Add `flow.tracers`, requiring `flow.visualization.absorption`. Tracers are visualization only, not concentration. Grid dye and velocity continue unchanged. Port ADR 0123's deterministic ring, passive RK2 midpoint integration, bounded substeps, exact mask-cell segment checks and mass-normalized, truncated Gaussian optical-depth splats. The public engine samples its collocated velocity texture manually at cell centres; its advection displacement is `dt * velocity` in simulation cells. Positions are stored in UV so simulation-resolution/aspect changes retain particles without a remap pass. Integration and travel limits are computed in simulation cells. Open-edge crossings retire particles; closed-edge/wall rejection retains the last wet position and mass.

The API measures sigma in **dye texels**, not the lab's velocity cells. Default sigma **0.75 dye texels** matches lab sigma .25 velocity cells at dyeScale 3. The valid sigma interval is0.25–4/3 dye texels: the lower bound ensures the ±3sigma square reaches at least one pixel centre at every phase; the upper bound fits the ±4-pixel normalization stencil, independent of dye-to-simulation scale. Source segments are sampled uniformly with a deterministic golden-ratio sequence; sources share the emission budget round-robin. The sampling serial repeats after 786432 emissions (divisible by 1, 2 and 3 sources), separately from the capacity-modulo ring cursor, bounding shader integer/float precision. Particle mass is stored in UV area: absolute normal collocated speed × segment length (both in simulation-cell units), divided by actual per-source emission rate and sim-grid cell count. Splat normalization multiplies UV mass by dye-grid pixel count only, so retained particles do not change optical depth on a hot sim-resolution/aspect change. This is bounded optical inventory, not a concentration/conservation claim; recycling deletes old inventory and wall rejection can stick particles.

Presence/capacity are Bucket C. Rate/sigma/sources are Bucket A. A fractional emission accumulator integrates each step's current rate; changing rate never reinterprets elapsed time. New-particle ages use exact emission crossings: newest age = remaining fraction/current rate, earlier retained emissions add1/current rate each. This includes carried fractions and overflow without midpoint-age bias. Counts exceeding capacity keep only the newest ring occupants. Resize replaces only the dye-resolution depth target; particle UVs/mass survive. Context restore rebuilds/reseeds with the existing opening-scene lifecycle. Dispose explicitly frees fields; never loses a context.

Optional update/splat/blend-probe programs are selected/prepared before config commit; shared programs live in gl-host. Every texture, uniform, VAO, framebuffer, viewport and blend setting used by tracer passes is bound in the engine's host scope. A display-only variant adds tracer optical depth before the existing absorption `exp(-depth)` and before glass. The legacy display/absorption shader source remains byte-identical when tracers are omitted. No route import, dependency, Svelte import or public GL type. Depth uses linear filtering when supported (state remains nearest); sigma remains dye-texel sized when enlarged on a canvas. Invalid/NaN carried mass is retired; nonfinite incoming speed emits zero mass. Removing tracers clears the capability-failure latch, allowing an explicit remove/re-add retry while retaining the one-warning-per-engine policy. The engine never settles while tracer resources are present; default-capacity GPU cost remains report-only, without a new post-hoc budget.

RGBA32F state completeness and an actual two-draw RGBA16F additive blend/readback probe gate capability. Initial capability failure frees partial tracer resources, warns once per engine and falls back to unchanged grid dye; no runtime capability exception escapes. A replacement allocation failure with healthy tracers instead rejects the requested transition before config/canvas mutation, preserving existing inventory and permitting retry.
