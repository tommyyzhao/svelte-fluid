# ADR 0117: Opt-in thermal transport and flame-salt emission

**Status:** Accepted
**Date:** 2026-10-18

## Context

Passive salt concentration cannot disappear in a continuously fed channel without a mass sink. Brightness must instead follow cooling, independently of transported salt mass. Legacy scenes must retain their exact solver/display path when these options are absent.

## Decision

Add opt-in `FlowSource.inflow`, scalar thermal coefficients, `flow.walls: 'no-slip'`, and `flow.visualization.emission`. All coefficient/source updates are uniform-only (Bucket A); optional targets follow presence/dimensions (Bucket C), display keywords follow emission presence (Bucket B). Prescribed textures rebuild only when their selected grid changes. Explicit `diffusivity: 0` preallocates the optional conduction target/program; explicit `radiativeCooling: 0` precompiles its program, so later zero/positive coefficient changes remain allocation/compile-free. Omission retains the legacy path and allocates nothing. Context restoration abandons the destroyed display Material before rebuilding; detaching its stale shader handles would produce INVALID_OPERATION.

An inflow relaxes supplied dye/scalar channels toward target `q*` with `w = 1-exp(-rate dt footprint)`: `q += w(q*-q)`. Unsupplied channels survive. Velocity remains additive. Dye alpha remains independently deposited thickness, never temperature or display opacity.

Temperature is dimensionless `theta=(T-Tambient)/(Tinlet-Tambient)`. Conduction solves `(I-alpha Laplacian) theta = theta_advected`, retaining an immutable dye-resolution RHS. The scalar-grid coefficient uses the existing screen-isotropic viscosity convention: `alpha = diffusivity dt max(W,H) min(W,H)/128`; hence `diffusivity/viscosity=1/Pr` on the same physical domain, including unequal dye/simulation resolutions. Each scalar-grid face is classified against the binary physical solid mask (top-down texture, Y-flipped), not the simulation-grid neighbor texture. Jacobi eliminates wall ghosts:

`theta = (theta_rhs + alpha sum_fluid theta_neighbor)/(1+alpha(Nfluid+2 Nwall))`.

Isothermal walls have ambient theta=0 half a cell away; insulated faces contribute neither numerator nor denominator. Open canvas faces have zero diffusive flux; closed canvas faces use the configured wall condition. No antialiased coverage multiply occurs in the thermal stencil. Thermal advection normalizes interpolation over fluid donors and clips traces at solids; nonthermal channels retain legacy advection/masking. Semi-Lagrangian advection is bounded, not globally conservative for arbitrary divergent/interpolated velocity; conservation checks isolate closed, stationary/parallel flow and report numerical error. Hardware sensitivity at viscosity .005, diffusivity .000714 versus .0000714 produced identical emission crossings (50% at .155, 5% at .405 of valve length): first-order numerical diffusion dominated physical cooling. For thermal fields only, existing opt-in `advectionScheme: 'maccormack'` therefore adds an immutable dye-resolution forward target and limited correction `q_hat + .5(q_old - A_reverse(q_hat))`. Clamp to the departure donor extrema; fall back to boundary-aware forward transport if either trace/stencil intersects a solid or canvas edge. Nonthermal scalar channels retain legacy transport; the correction bounds extrema, not global energy, and does not change default scenes. Hardware moving-sine tests isolated same-grid and 4× scalar-grid transport: full-float MacCormack reduced RMS by more than 2× versus full-float SL, while half-float erased the small correction and accumulated roundoff. Thermal scalar/forward/RHS targets therefore use RGBA32F when WebGL2, EXT_color_buffer_float and OES_texture_float_linear are available. Unsupported devices retain half-float (and the existing no-linear-filtering scheme fallback); they must not claim precision-equivalent physical cooling. Presence transitions copy the persistent scalar into its new format; resizing, context restoration, disposal and byte estimates follow that format. Emission and all nonthermal-only targets remain half-float. Real-scene dt halving later reduced downstream salt from 2.28 to 1.06 while nozzle temperature changed only .26% and nozzle salt increased: legacy mediump/half-float salt advection had the same numerical-loss problem. Emission-enabled dye therefore also uses full-float storage and the same boundary-aware, donor-limited RGB transport, sequentially reusing the scalar forward scratch. Alpha thickness retains first-order advection/masking/ceiling; reveal, distortion and sticky transport retain their authoritative legacy paths. Precision toggles preserve persistent contents; default dye remains half-float.

On float-capable thermal conduction, preallocate an R32F RHS and R32F ping-pong scratch alongside the RGBA RHS. When exactly one physical scalar channel diffuses, extract it into the R32F RHS, start Jacobi from that immutable RHS, retain the identical face stencil/arithmetic, then merge only that channel into the unchanged RGBA scalar. Multi-channel and unsupported cases retain the RGBA solve. Persistent scalar/dye formats, advection, timestep and iteration semantics do not change. Presence/dimensions own these optional targets, not coefficient values, keeping zero/positive coefficient and channel updates allocation/compile-free. Context restoration abandons/recreates them; resize, disposal and resource-byte accounting include all three R32F targets. Retaining RGBA RHS permits hot transitions into multi-channel conduction without allocation.

Opt-in no-slip viscosity eliminates zero-velocity ghosts using the same `Nfluid+2 Nwall` denominator for both velocity components; open edges have zero gradient. Free-slip arithmetic remains unchanged. Projection still uses the existing collocated constant-density pressure scheme; it is not a staggered finite-volume CFD discretization.

Optional optically thin *net* radiation is `dtheta/dt=-k[(1+(R-1)theta)^4-1]/(R^4-1)`, `R=Tinlet/Tambient>=1.01 (the floor keeps the normalized net-radiation denominator resolved in float32; the shader also clamps that denominator to 1e-6)`. A bounded monotone backward-Euler root solve preserves the ambient fixed point and nonnegativity. `k` is declared heat loss per second at inlet temperature, not hidden dissipation.

Linear-light emitted radiance is `max(saltRGB,0) intensity exp[-chi(1/That-1)]`, `That=(1+(R-1)max(theta,0))/R`. An HDR dye-resolution target is prepared before bloom in both render paths. Bloom and display sample emission, not cold dye; sunrays use a separate scratch target. Display adds bloom linearly, tone maps once, sRGB encodes once; field-overlay max composition is disabled. Thickness remains in dye alpha and is preserved in emission alpha for optional surface geometry.

## Consequences

- Default output is pixel-identical in disabled-feature hardware regressions; shader source differs by inactive inflow/no-slip branches, not by default arithmetic. New optional shaders/targets are allocated lazily and covered through resize, toggle, restore, shared interleaving and disposal. Without linear filtering, thermal velocity and legacy/thickness sampling use manual bilinear reconstruction; the bounded thermal donor interpolation is already explicit. Emission uses linear filtering when supported; transient thermal scratch targets remain nearest-filtered.
- Diffusion iteration/resolution/timestep adequacy must be measured, not assumed. For the flame test route's dt=1/240 and 3072×1024 scalar grid, alpha=.16384 gives infinity-norm contraction rho=4alpha/(1+4alpha)=.395902; rho^18<=2^-24 for a unit-bounded field. The route uses 20 iterations (two margin), not 80. This does not change library defaults. The analogous real-arithmetic viscosity bound does not pin a half-float Jacobi iterate: 10 versus 40 velocity iterations changed downstream salt and discharge, so the route retains 40. High dye resolution plus Jacobi conduction remains intentionally expensive.
- RGB salts share one effective excitation law, not independent species spectroscopy. Constant-density flow omits hot-gas expansion, chemistry, variable properties and combustion. This is a reduced thermal-emission model, not calibrated CFD.
- A dark stalled jet fails the preview fade criterion. Fade is evaluated only after positive outlet flux and downstream salt arrival; no outlet drain, display fade or artificial dissipation may manufacture success.
- The current flame preview passes the original fixed dark-tail/inlet/chroma gate at dt=1/240, but progressive 50%/5% fade positions remain early. Pressure iteration doubling changes outlet speed substantially; timestep halving still changes salt concentration/fade after full-float correction. No calibrated/converged-flow claim is justified. A plausible, unproven contributor is first-order fallback near solids: repeated interpolation in the narrow wall-adjacent channel remains timestep-dependent. Principled follow-up: conservative flux-limited finite-volume transport and a converged pressure solver (for example multigrid), not more display fading.

## Amendment (2026-11-16): flame-jet gate status

On Chrome for Testing 154 (Apple M1 Max), the registered `flame-jet` scene gate fails one criterion: `shoulderChroma` is 0.0760, against a threshold of > 0.08. The other criteria pass (tail/head ratio 0.0038, inlet luminance 0.91, tail display luminance 0.0069). The sprint tip (00b0707) and the integrated branch produce bit-identical metrics, so this is environment drift since registration, not an integration regression. The threshold is not loosened after the fact. The test moves to the opt-in measurement set (`SVELTE_FLUID_GPU_BENCH=1`): it runs 7200 steps on a 3072×1024 scalar grid, exceeds CI's SwiftShader time budget, and measures a laboratory scene rather than a library contract.
